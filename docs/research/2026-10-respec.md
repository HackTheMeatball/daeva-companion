# Respec: stigma reset and Daevanion reset (0.9 P20, Jane's D1 / D2)

Game Data Check, 2026-10-20. Research only. Read 2026-10-20 with our User-Agent, ≥ 10 s apart: Metabot
`/guides/stigma-guide`, daevaguides `/en/guides/stigmas-guide/` and `/en/guides/daevanion-guide/` (both Full). Facts only.

## D1: stigmas

| Question | Answer | Sources | Label |
|---|---|---|---|
| Does a stigma reset refund the shards? | Yes. Resetting a stigma skill returns the Stigma Shard points spent on it, and the reset messages confirm it | Metabot; daevaguides (credits Metabot) | single source (daevaguides repeats Metabot) |
| Does a reset cost something? | Yes. It has its own cost, and the client blocks a reset you can't pay | Metabot; daevaguides (Kinah) | 2+ sources that it costs; the **Global price is unknown** |
| How much? | KR: 10,000 Kinah per point from 28 Jan 2026, later dropped (daevaguides, from aion2hub / ExpCarry). Global: "nobody has posted the global price". Read it on the confirmation screen | daevaguides | KR only; Global needs an owner screen |
| Does unequipping refund or reset? | No source says. Metabot: a stigma works only while registered to a stigma quickslot (Quick Use 9–12). Levels are bought on the stigma skill itself, so unequipping keeps them | — | **inferred**; owner check |
| When can you swap? | Not in combat ("the client blocks swaps in combat") | Metabot | single source (game behaviour as described) |
| Do Daevanion nodes raise stigmas? | No. The boards raise only active and passive skills | Metabot | single source |

## D2: Daevanion

| Question | Answer | Sources | Label |
|---|---|---|---|
| Can you undo a node? | Yes. You remove a node and get its point back | daevaguides | single source |
| One node or a whole board? | daevaguides describes only removing single nodes. It suggests buying a weak connector, reaching the good node, then checking whether the connector can be removed, which implies a node another node depends on can't go. No source names a whole-board or per-board reset button | daevaguides | single source; **per-board reset unknown**, owner check |
| Cost | Kinah. KR: 500 Kinah per node (Inven, exitlag, via daevaguides). Global: unknown; one creator quoted 24,000 Kinah without saying for how many nodes | daevaguides | KR only; Global needs an owner screen |
| "Acquire All Nodes" | Buys the whole board. Only worth it after 45 when you can afford everything; then remove the weakest nodes | daevaguides | single source |

## For the design

- **Safe to build now:** the stigma reset refunds shards (Metabot), costs something, and can't happen in combat. A node
  comes back with its point.
- **Show as "check in game":** the price of either reset on Global, whether a per-board Daevanion reset exists, and
  whether unequipping a stigma does anything to its levels.
- **Owner check, one sitting, 3 screens:** the stigma reset confirmation window (price), the Daevanion remove
  confirmation for one node (price), and whether the board window has a reset-all control.
