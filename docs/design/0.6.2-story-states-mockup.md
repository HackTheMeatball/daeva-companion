# 0.6.2: the story card's icon follows the quest's state

Release Planner (Walter), 2026-10-18 8:21 PM ET, `design: yes` (#391, behind P13): Isaac sent the game's four story-quest
states (available, active, ready to turn in, journal check), the last at 8:20 PM ET ("This is the story quest icon when
a quest is done and just needs to be turned in"). Design Lead (Jane) mockup; docs and screenshots only, nothing in `src/`
changes.

- Frames: `docs/design/mockups/0.6.2-story-states/*.png`, drawn on the real built page by its `cases.mjs`
  (`npm run build && node tests/support/shots.mjs docs/design/mockups/0.6.2-story-states --after-only`;
  `MOCK_BEFORE=1` shoots today's page). Before and after pairs: `docs/reviews/0.6.2-mockup-story-states-shots/`.
- Icons are Isaac's own crops: `docs/research/owner-screens-2026-10-18/` (active, journal check) and
  `story-quest-ready-to-turn-in.png` here. DECISIONS `owner-ok-story-icon` covers only the active one.

## 1. Where the state shows: the Next up story card only

| State | When (data the app already has) | Icon | Count line |
|---|---|---|---|
| Active | objectives open (`qsteps` short of every step but Turn in) | active crop | "2/3 objectives", as today |
| Ready to turn in | every objective ticked but the quest's own "Turn in" step | ready-to-turn-in crop | **"Ready to turn in"** instead of "3/3 objectives" |
| Done | the guide's story is over (`storyEnd`, the "Lv 45 story complete" card) | journal check | as today |

- "Ready" comes from the objectives the player ticks, so no new data and no auto-detection. Each quest's last step is
  its "Turn in" row (QUEST_STEPS, for example Cemetery Cleanup: "Turn in, Tagar (Gravekeeper), Gravekeeper Camp"), and
  that row stays listed under the card, so the card says both that you're done and who to go to.
- The "done" icon only shows on the end-of-story card: after "Turned in" the card moves on to the next quest, which
  starts out active again.
- "Available" (not picked up) is not used. The card always shows the quest you're on; a level-gated quest keeps the
  active icon with its "Opens at Lv X" line, as P13 has it.
- **The Journey main-story list stays as it is.** Each row already has its tick box, so a state icon there would say
  the same thing twice.

## 2. The tile

- The crops have the game's dark background baked in. On today's accent-filled tile they would read as a box in a box,
  so the story icon fills a **dark tile** (`--panel-2`, `--line` border, the tile's own radius) that it covers edge to
  edge. P13 should use the same tile for its active icon, so this item doesn't have to restyle it.
- The ready crop (55×68) is taller than the others (47×50, 58×55). The build trims all three to the same square around
  the emblem so they sit at one size (in the frames the ready one looks a little small).
- The emoji stays the fallback when an icon can't load. The tile gets `role="img"` with the state as its label
  ("Active quest", "Ready to turn in", "Story complete"), so screen readers get the state the icon shows.
