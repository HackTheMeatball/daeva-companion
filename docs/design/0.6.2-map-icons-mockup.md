## 1. The set, and where each icon goes

One rule for the whole set: a marker shows **where the page names that kind of place**, in the same size and slot
every time. It never decorates rows that are already in a list of that kind.

| Marker | File (source) | Where | Not |
|---|---|---|---|
| Sealed Dungeon (ring) | `sealed.png` (Metabot) | Next up Sealed Dungeon card tile (replaces ⛏); the Dungeons card's "Sealed Dungeons" heading | each dungeon row (all are dungeons) |
| Stronghold (campfire) | `garrison.png` (Metabot) | Next up Stronghold card tile (replaces 🏰); the "Strongholds" heading | each stronghold row |
| Kibelisk (purple crest) | `TeleportArtifact_Dark_Engraved` (aion2quest) | before the word "Kibelisk" on Next up cards and in their `i` notes | milestone rows (they keep text, as with item icons) |
| Empyrean Trace (feather) | `trace.png` (Metabot) | region rows' trace count: "29 [feather]", the icon standing in for the word "traces" (label and tooltip "Empyrean Traces") | step text |
| Story quest states | active: Metabot `quest_hero` (the inner-diamond icon, which P13 builds with); ready to turn in and journal check: owner's crops | the story card (#391, already decided there) | |

- **Tiles:** every game marker sits on the **dark tile** (`--panel-2`, `--line` border) that #391 set for the story
  icon, at 70 % of the tile. A red tile stays for app actions (Level up, skill buys), so the colour now tells you "a
  place in the game" vs "something to do in the app".
- **Inline:** 1.25 em, before the word, kept on one line with it. Headings get an 18 px marker before the label.
- **The trace count drops the word** because the region row is tight. With "19 [feather] traces", "Dredgion Crash
  Site" wrapped to two lines at desktop width (first frames). The word stays as the icon's label for screen readers
  and as a hover tooltip.
- **Kibelisk:** Metabot's `kisk_dark` is white, while the game's Asmodian Kibelisk is the purple crest in Isaac's crop.
  Source Vetting picked aion2quest's purple one, the exception to "Metabot first". That's an owner call (Q3).

## 2. Held back: points of interest, campsite, updraft, field boss, undiscovered

- No page text names these as a type today. Steps say "Dredgion Crash Site" or "Quai Campsite" as plain place names,
  and the data doesn't say which kind of place each one is. Putting a marker on them would mean guessing, or tagging
  places by hand in free text, which is the scatter Walter warned about.
- They join the set once the data has a place type (for example `kind: "campsite"` on a place record). That's a data
  item, not a design one. The table above already fixes their size and slot.
- The files are recorded: Metabot `teleporter` (campsite, probable, Isaac to compare), `updraft`, aion2quest red skull
  (field boss), gold "?" (undiscovered, probable), and Isaac's crop for the crossed-swords point of interest.
