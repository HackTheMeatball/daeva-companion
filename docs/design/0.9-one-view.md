# 0.9: one view (the hide list for P21)

The owner's direction, 2026-10-20 9:45 PM UTC (5:45 PM ET), project chat: "same thing with "basic" and "advanced" mode like
that might not be necessary so make sure that's reviewed to see if it really needs to exist or we can just make one
better version, so we don't have to maintain two views." Decided after review (Design Lead, Jane), with Holly and an outside critic
agreeing (`design-review/critic-product-calls-2026-10-20.md` items 1–6, `review-product-calls-2026-10-20-holly.md`). The
north star (owner, 5:42 PM ET): "open the app, follow the next up and it's always the best thing you could be doing for your
character."

**The rule:** one view. It shows what Basic shows today, plus each card's foot. Everything only Advanced shows today is
either open, in a fold that starts closed, or dropped, as listed below. Every drop is named here, so the outside reviewer
sees it before P21 is built (K26 baseline). The view switch (`.modeseg`, Basic / Advanced) is removed.

**Where fold state lives:** the save's existing `open` map (one entry per fold id), the same one the drawers and folds use
today. No new field. `mode` is no longer read. Saves keep it untouched (pre-1.0, no key bump), and it leaves the
bug-report payload (`src/main.js:508`).

**The default flips** (critic 2): a save with no `mode` opens in Advanced today (`src/main.js:210`). After P21 every
player sees the one view, which is closer to Basic. The folds below are where the rest goes, and the drops are the only
things that leave.
