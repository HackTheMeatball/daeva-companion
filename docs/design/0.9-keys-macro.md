## 1. The simple "autopilot" layout: a "How you play" block, not a mode

The owner asked for a simple layout (hold left / right click plus Q / E / R / F) alongside the advanced split.

- **Where:** it's the first block of Key setup, always open, above the grid: **How you play**, one line per thing you
  press. The grid and macro sit under it in a fold, **Your keys and macro**, which remembers whether it's open, like every
  fold (one view, DECISIONS "One view", owner 2026-10-20). It isn't a Simple / Advanced switch, because two views of
  the same keys are the thing the owner asked us to stop maintaining. "Alongside" is met by the two sitting on one page,
  the simple one first.
- **Lines** (Assassin, `22-play-macro-*`):
  - **Hold** `Right` + `Left`: runs the macro below, with Quick Slice refilling MP · holding right click alone runs out
    of MP (fact 10).
  - **Tap** `Q`: the Q stack's row 0 skill, with its icon (Shadowstrike, to get behind the target).
  - **Tap** `E`: the E stack (the stigmas), or "Your stigmas, when one is equipped" before the first.
  - One line per other key the guide's build fills, in the grid's key order. Each key chip shows the player's own key
    once they've rebound it (#388).
- **Not R or F.** R isn't a key of its own. By default it's left click's second key (fact 11), so "hold left click" already
  covers it. F holds no skill (F1–F8 are consumables, fact 11). So the block shows the keys the game actually lets a
  skill sit on. That follows the owner's own rule that the skill bar matches the game exactly (beta B4), so it isn't a
  question for him. If he wants a word on it, P22's shots go to him anyway.
- **A class with only default keys** (no guide build yet, such as the Gladiator in `12-sheet-gladiator-*`): the block lists
  the default keys' row 0 skills the same way. With no macro in the data, the Hold line reads "Hold `Left`: Quick
  Slice" (the class's left-click skill). No line is drawn for something the data doesn't have.
- **Phone:** each line stacks, keys first and the words under them (`22-play-macro-390`).

## 2. The macro as steps

The old mock draws the macro as "Set the macro once" (three how-to lines) plus one stack. Facts 4–7 and 12 say a macro is
an ordered list of steps. Each step fires a whole key's stack (rows 0–3) or a single skill, there can be up to 20 steps,
each step has its own Delay, and stepping through two or more keys cycles more than 4 skills.

- **Heading:** "Macro on right click", or on whichever key the data puts it (fact 6: any key with a 0–3 row; several
  macros give several blocks, each with its own heading). When a macro has more than one step, the heading adds the
  count: "· 3 steps, 7 skills".
- **One row per step, numbered as in the game's Macro window** (`22-macro-steps-*`):
  - A key step: the key chip, the quickslot's name ("Quick Use 2", as the game labels it), that stack's icons in fire
    order (row 0 first), and "Fires that key's stack, row 0 first". With a single step, the sub-line names the skills
    instead ("Heart Gore, then Ambush, then Savage Roar").
  - A single-skill step: the icon and name with "· one skill". Only where the data has one (fact 5).
- **Delay:** under each step, a divider line reading "Delay **10** ms", drawn like the game's own. It's the value the
  player edits in game (fact 12). 10 ms may be called the game's default (fact 12a, T-123). The app shows the value and
  doesn't take input for it (no new save field). If the data ever carries a per-step delay, that value replaces 10.
- **Under the list:** "Set it in game: K → Macro → Add Macro, one step per line here. Each step's Delay starts at 10 ms,
  the game's default; you can change it there." With 2 or more steps it also says "Up to 20 steps. Left click can only be
  the last step." (facts 6 and 7).
- The macro rows and the grid name the same keys, so a rebound key (#388) shows on both.
- Steps follow the level like the grid does. At a level where a step's key holds nothing yet, that step isn't drawn.

## Accessibility

- "How you play" is an ordered list. Each line's accessible text reads as a sentence ("Hold Right and Left: runs the
  macro …").
- Macro steps are an ordered list. A step's accessible name names its key and skills ("Step 1, T, Quick Use 2: Heart Gore,
  Ambush, Savage Roar"). The delay divider is text ("Delay 10 ms"), not decoration.
- The fold's summary is at least 44 px tall.
