## 9. Respec on every card

Today Skills and Daevanion have a Respec button that needs a second click within 3 s and can't be undone. Stigmas have
no Respec. Daevanion's clears every board.

**Option A, recommended** (`09-dv-menu-*`): Daevanion's footer button reads "Respec ▾" and opens a short menu. It has one
row per open board, with how many nodes it would untick, then a divider and "All boards". A board with nothing ticked is
greyed out ("none yet"), and a board that isn't open isn't listed.
- The three cards keep the same footer: Respec sits at the right end on Skills, Daevanion and Stigmas.
- Picking a row does it at once and shows a toast with Undo (`09-dv-undo-*`: "Respecced Nezekan: 10 nodes unticked ·
  Undo"). That replaces "Click again to respec", so all three respecs become undoable, which matches the owner's
  "undoable" rule for anything that changes progress.

**Option B** (`09-dv-perboard-*`): a small Respec chip on each board's line in All nodes, with "Respec all" in the footer.
Not recommended: the per-board control is hidden until you open All nodes, which is the longest list in the app, and it
adds a second control style.

**Stigmas** (`09-st-respec-*`, `09-st-undo-*`): a plain Respec button at the right end of the footer. It sets every
stigma back to level 1, keeps them equipped and returns the shards: "Stigmas reset · 18 shards back · Undo". In the
seed save that's Triniel's Dagger Lv 10 (14 shards) and Illusive Clone Lv 5 (4 shards), from the card's own cost table.
- One action, so no menu.

Basic mode shows the same controls (`09-dv-menu-basic-390`). That's note 7, a 0.8.1 build item, which Basic needs either way.

**Cost:** no new height; the menu is a popover. Build work is one shared footer control and the Undo toast, which
already exists for rewards (`rewardToast`). It needs no new save field.

**Data questions (Game Data Check):**
- D1. Does the game's stigma reset refund every shard, and does it unequip? If it unequips, the toast says so and the
  slots tick off too.
- D2. Does the game have a per-board Daevanion reset, and what does it cost in Kina or items? If only an all-boards reset
  exists in game, Option A still helps fix the app's record, and the row names say "in the app" in their tooltip.

## 10. Catch-up for late starts

Isaac: at Lv 39 the app "steps me through leveling up skills in the same order i would have unlocked them in game … rather
than just saying 'level this skill from 1-x, pick x,y,z specialty' then moving to the next skill". Today that's 77
one-level steps.

**Numbers in the frames are measured, not invented.** I bought every open upgrade in today's build for a fresh Lv 39
save (165 points). The guide's own spend ends at 7 skills at 10 and Insignia Explosion at 9, with 1 point left. The
specialty picks come from `builds.json` `specialtyPicks`.

**When it shows:** when your points cover upgrades on 3 or more skills at once. That covers a late start, the state
after a Skills respec (note 8) and a long break. Below that, today's one-at-a-time hero stays.
- The rule's threshold is my inference. **Test:** count how often a normal level-by-level player hits 3 or more at
  once, from the Lv 1–45 journey suite. If it ever happens on a normal path, raise the threshold.

**Skills card** (`10-skills-start-*`, `10-skills-mid-*`): the hero and Coming up become a "Catch up" list, with a bar for
"N of 8 skills".
- One row per skill in priority order: icon, "Heart Gore 1 → 10", then "Active · 21 pts · specialty: Up to +20%
  Critical Hit when fewer targets are hit". Passives have no specialty.
- Each row has a Done button, which ticks that skill's lines up to its level and the slot 1 specialty. A done row is
  struck through with a ✓, and Undo is in the toast.
- A skill the points don't fully cover says so: "Lv 10 needs 3 more pts".
- The footer says "1 pt left over" and offers "Mark all done", for a player who already set everything in game.
- When the last row is done, the card goes back to today's hero.

**Next up, option A, recommended** (`10-nextup-a-*`): one card per skill, in the list's order. The band reads "Catch up ·
skill 1 of 8", the title "Level Heart Gore 1 → 10", then "21 pts · then pick the specialty …", the K hint, and Done.
This is what Isaac described.

**Next up, option B** (`10-nextup-b-*`): one card for the whole catch-up ("Catch up 8 skills · 164 of your 165 pts · Heart
Gore first", with Show list). It's fewer cards, but Next up stops naming the next action, which is its job.

**Cost:** the Skills card grows by about 3 rows at 390 against today's hero plus Coming up. It replaces both, so the
page doesn't grow. Build work is a new Skills view and a new Next up kind. It needs no save field, because a row is done
when its lines are ticked.

**Out of scope here, but it touches this:** slot 2 specialties (notes 5 and 6, 0.8.1). Heart Gore and Quick Slice reach
slot 2 at effective skill level 12, which is 10 plus board nodes. Once 0.8.1 lands, a row whose board nodes take it to 12
adds "· slot 2: Multi-Hit on hit" to its line.

## 11 + #388. Key setup as its own sheet, with your own keys

Today Key setup is a fold at the bottom of the Build drawer. On desktop it's a 320 px column, so the grid's boxes are
small and the macro steps run long. Isaac asked whether it should pop up from the bottom on desktop, and #388 asks to
let players set their own keys.

**One design for both:** on desktop, Key setup opens a bottom sheet over the page (`11-sheet-today-1500`).
- Its width is up to 1080 px. It has a grabber and a close button, and Esc closes it.
- The left side has the grid with the key chips under it, the left-click line and "Coming to E".
- The right side has "Set the macro once" (the three steps), Game default keys and the row-order note.
- The drawer keeps Stat priority and Rotation, and its Key setup fold becomes a "Key setup ↑" button.

**On a phone** the Build drawer is already a bottom sheet, so Key setup opens as a full-height sheet on top of it, and
closing it returns to the drawer (`*-390`). Everything is one column, grid first.

**Your own keys (#388)** (`388-key-listen-*`, `388-key-mine-*`): each key chip under a column is a button with a small
caret. Tapping it changes the chip to "Press a key", with "Esc cancels" under the grid, and the next key you press
becomes that column's key.
- Keys you set get a gold edge, and a "Back to suggested" link appears.
- The Rotation lines, the Next up hint chips and the drawer's text all use your keys.
- Phones have no keyboard, so tapping the chip there opens the browser's own picker with the keys AION 2 lets you bind.
  That list is a data question (D3).

Basic mode keeps the suggested keys, with no carets, as #388 says.

**Cost:** the drawer gets shorter by the whole fold. Build work is a sheet component, which is the first in the app,
and one save field (`keys`: column → key, defaulting to the suggestion). Adding a field with a default needs no key bump
before 1.0.

**Data question:** D3. Which keys can AION 2 bind a skill stack to? Until that's sourced, the phone picker lists the
keys already in the build data (Q, E, T, 1–4).

## 12. Icons fill the key boxes

(`12-sheet-fill-*`, `12-sheet-tip-*`; 360 in `12-sheet-fill-360`)
- Each box is the skill's icon, square and filling the box edge to edge: 76 px on desktop, up to 88 px on a phone.
- The name leaves the box. It's already in the Rotation and in each box's accessible name ("Illusive Clone, E, row 0
  (fires first)").
- Hover on desktop, or tap on a phone, shows a tooltip: "Illusive Clone · E, row 0 (fires first)".
- Row 0 keeps its light edge and stigmas keep their accent edge. An empty row stays dashed.

**Cost:** CSS only, plus the tap tooltip on phones. No height change on desktop.
