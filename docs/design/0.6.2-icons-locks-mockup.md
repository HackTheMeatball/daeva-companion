Owner asks (project chat, 2026-10-18 7:55 PM ET, with screenshots): (1) the Key setup grid in the Build drawer should
show skill icons, not just names; (2) at Lv 4 in Basic the Skills card sits alone in its row and the blank space next
to it looks odd, so show a placeholder card with "unlocks at Lv X" and/or "in N levels". Design Lead (Jane) mockup;
docs and screenshots only, nothing in `src/` changes.

- Frames: `docs/design/mockups/0.6.2-icons-locks/*.png`, drawn on the real built page by
  `docs/design/mockups/0.6.2-icons-locks/cases.mjs` (each case rewrites the DOM and adds one style block):
  `npm run build && node tests/support/shots.mjs docs/design/mockups/0.6.2-icons-locks --after-only`.
- Only existing tokens and the app's own icons (`assets/icons`). No new art.

## 1. Key setup grid with icons (k1, k2, k3)

- Each filled cell: the skill's icon (32 px, `--radius-6`) centred on top, the name under it (mono 11 px, centred, up to
  two lines). All cells in the grid get the same height (72 px), empty ones too, so rows stay level.
- Words never break in the middle. Today `.sk` has `overflow-wrap: break-word`, which splits "Shadowstrike" as
  "Shadowstr / ike" in the drawer (owner's screenshot). The build sets `overflow-wrap: normal` for grid cells.
- The row-0 outline (white) and stigma outline (accent) stay as they are; so do the "new" marks.
- A skill with no icon gets the existing initials square (`spmini ini` look, 32 px). **Shadowstrike has no icon today**
  (k1, k3 show "S"); the build adds it under the standing icon OK (Metabot first, recorded in `docs/ISSUES.md`), or lists
  it for the owner if no approved source has it.
- Left click: the same icon (24 px) before "Quick Slice", one row.
- "Coming to E" is unchanged (it already has small icons).
- Why icon **and** name, not icon only: the game's K window shows icons, so the icon is what you match; the name stays
  for the skills you don't know by sight yet and for screen readers. Icon-only would need a hover to name it, and hover
  doesn't exist on a phone.
- Phone (k3, 390 px): three columns fit; the longest names ("Insignia Explosion", "Illusive Clone") wrap between words.

## 1a. Key labels the player can change (k4, k5)

Owner, 2026-10-18 8:11 PM ET: he plays Shadowstrike on E, not Q, and wants players to set their own keys (#388, a 0.8
candidate). This page only leaves room for it.

- Key labels move **under** their column as key chips, like the game's skill bar (owner's side-by-side: keys along the
  bottom, row 0 at the bottom, stacks growing up). Our row order already matches (3 on top, 0 at the bottom).
- A chip fits up to about 12 characters ("Right click", "Shift+Q", "Mouse 4") on one line at 390 px. Longer key names
  are shortened by the item that makes keys changeable, not wrapped.
- No key picker here: letting players set their own keys is a separate 0.8 candidate (#388). The chips only avoid a
  layout that hard-codes key names, so that item can change the labels without moving anything.
- Left click stays its own line under the grid.

## 1b. Right-click macro walk-through (k4, k5)

Owner, 2026-10-18 8:01-8:08 PM ET, with screenshots: the macro "could probably be better explained or easily
visualized". The three-item list in Key setup becomes a numbered walk-through:

1. `Esc` → Settings → Key Settings → General, scroll to Gameplay.
2. Macro → press `Right click` → Confirm. Says what you'll see: "Already in use for [Skill Quickslot: Quick Use 2]".
3. `Esc` → `K` → Macro (above Active). Says the first time it's empty: "No macros available."
4. Click Quick Slice → set it to Quickslot 2.
5. Add Macro → add the right-click stack in order (each shown with its icon).
6. Hold `Right click` + `Left click` in a fight.

- Each step is a path of chips: keys in gold key chips (the unlock-line style), menu names in plain chips, arrows muted.
  One muted line under a step says what you'll see. Names and keys come from `data/` with the rest of the guide text.
- **Drawn, not screenshots.** No game screenshots in the app (CLAUDE.md: no new game art without the owner's OK); the
  quoted game texts are short UI strings, and the only art is our existing skill icons.
- The Rotation (what to press when) and this macro block stay two separate blocks (owner, 8:12 PM ET: "rotation list
  and macro list are separate").
- **The content is the owner's steps and still needs an in-game check (#387).** Step 5 shows the stack the owner named
  at 8:12 PM ET ("hold right click and all the skills in my quickslot 2 (heart gore, ambush, savage roar) fire
  automatically"); his earlier screenshot showed Heart Gore then Quick Slice. Step 4 is from his message. They differ from today's guide text ("Step 1 = the right-click macro slot") and from today's Key setup (his bar
  stacks Heart Gore / Ambush / Savage Roar under T, with Quick Slice on the macro slot). Game Data Check confirms the
  steps before the build; the build uses whatever that check settles.
