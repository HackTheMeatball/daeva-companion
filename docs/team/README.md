# Team

The team is the standing threads of the Claude project, each owning one job. This folder no longer defines who does
what:

- **Who does what:** the "Who does what" table in [docs/kaizen/LEDGER.md](../kaizen/LEDGER.md#who-does-what). It names
  one owner per kind of work, and work is routed only from it.
- **Rules and decisions:** [docs/kaizen/ledger.csv](../kaizen/ledger.csv) lists every rule with its owner and its one
  home; [docs/DECISIONS.md](../DECISIONS.md) holds Isaac's decisions.
- **Working rules for every session:** [CLAUDE.md](../../CLAUDE.md).

The department charters in this folder (engineering.md, qa-release.md and the rest) come from the earlier one-CEO setup.
They are kept for their *Standing notes*, which hold engineering facts other docs link to, not as role definitions.
Where a charter disagrees with the ledger, the ledger and its homes win. Merging is auto-merge only, never by hand
(MRG-01).
